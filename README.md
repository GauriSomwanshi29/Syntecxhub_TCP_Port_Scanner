# 🌐 Syntecxhub Port Scanner

A simple and efficient TCP Port Scanner built using Python and socket programming.  
This project scans a target host for open ports within a specified range and helps understand networking and cybersecurity basics.

---

## ✨ Features

✅ TCP Port Scanning  
✅ Scan Custom Port Ranges  
✅ Detect Open Ports  
✅ Fast Socket-Based Scanning  
✅ Beginner-Friendly CLI Interface  
✅ Simple and Lightweight Project  

---

## 🛠️ Technologies Used

- 🐍 Python
- 🌐 Socket Programming
- 💻 VS Code

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/Syntecxhub_Port_Scanner.git
```

Move into project folder:

```bash
cd Syntecxhub_Port_Scanner
```

---

## ▶️ Run Project

```bash
python port_scanner.py
```
